## 三、PM 优化建议

### 3.1 P0 — 新增「完整测试板块」

**背景：** 当前 M1 有课程、路径、共学营、搭子四大内容形态，但**没有任何测试/考核机制**，用户学了没学会无法验证。

**建议设计：**

```
课程详情页（独立路由 /course/:id）新增：
├── 章节学习
│   └── 章节内嵌小测（每章3-5题）
├── 单元测试（每单元结束后）
├── 结业考试（课程全部完成后）
└── 作业提交区（可上传附件）
```

**功能点：**
- Quiz 组件：单选/多选/判断/简答，实时评分 + 解析
- Exam 组件：计时考试，提交后显示分数与排名
- Assignment 组件：文本/文件上传，AI 辅助批改占位
- 进度解锁：完成上一章quiz才能解锁下一章

### 3.2 P1 — 搜索结果页与空状态

**问题：** 搜索输入后直接按 Enter，没有展示搜索结果列表，也没有空状态提示。

**建议：**
- 搜索框回车 → 展示过滤后的课程/路径/导师列表
- 无结果时显示：`🔍 未找到"xxx"，试试其他关键词？`
- 热门搜索词推荐 chips

### 3.3 P1 — 课程详情页（从侧边面板升级为独立页面）

**问题：** 右侧滑出面板（340px）空间受限，无法展示课程章节大纲、讲师详细介绍、用户评价等完整信息。

**建议：** 使用 React Router 或 App 内部 state 路由，课程点击 → 全页课程详情，包含：
- 课程介绍 + 大纲目录（可折叠章节）
- 讲师详情卡
- 用户评价区（头像 + 评分 + 评论）
- 相关推荐课程
- 底部固定 CTA（购买 / 免费学习 / 试听）

### 3.4 P1 — 学习路径升级为独立 Tab

**问题：** 学习路径目前混杂在 M1 信息流中，与课程卡片挤在一起，缺少独立的"学习路径"Tab。

**建议：** 在 M1 顶部新增第三个 Tab 级别：
```
[全部] [入门] [进阶] [高级] [免费]  ← 课程分类（横向）
同时新增 Tab：[课程] [路径] [共学营] [搭子]  ← 内容类型（纵向）
```

### 3.5 P2 — 共学营增加成员头像墙与实时进度

**问题：** 共学营卡片仅显示"847人已报名"（静态数字），无成员头像墙，无开营倒计时。

**建议：**
- 成员头像墙（最多显示8个 + "+N"溢出）
- 开营前显示倒计时：`距离开营还有 X 天 X 小时`
- 已报名状态切换（未报名 → 已报名 → 进入学习群）
- 当前状态用绿色实心dot标识

### 3.6 P2 — 学习搭子算法说明与搭子匹配分透明度

**问题：** "94% 匹配"没有说明匹配依据，用户无法判断是否可信。

**建议：**
- 点击匹配分显示算法说明浮层：
  > "匹配依据：你们都学习了《数字人从入门到变现》，都在学习『AI副业』方向，学习进度相近"
- 搭子申请需要对方确认（当前是直接"发起搭子"无确认流）

### 3.7 P2 — 六维测评结果应用

**问题：** 六维测评做完只显示路径推荐，但测评结果没有持久化存储，用户下次进入看不到历史测评。

**建议：**
- 测评结果存入 localStorage，显示"最近测评：X天前"
- 测评结果可分享为图片（社交传播）
- 测评后解锁对应难度课程（入门/进阶/高级标签动态调整）

### 3.8 P3 — 课程播放页（视频学习区）

**长期规划：** 当前课程仅有信息展示，缺少真正的视频学习体验。
- 视频播放器（支持倍速、字幕、笔记时间戳）
- 学习笔记（记在视频时间线上）
- 课程内quiz打断（看5分钟视频 → 做1道题 → 继续）

## 四、设计层面优化建议

### 4.1 卡片信息密度问题

**问题：** 特色课程卡片（FeaturedCourseBlock）尺寸很大（3列×4行），但右侧小课程卡片仅 70px 图片高度，信息密度差异过大。

**建议：**
- 统一小卡片的图片高度至 90-100px
- 或增加小卡片的标签行（如难度、价格并排显示）

### 4.2 颜色规范一致性

**问题：** 浅色模式下，部分组件仍使用硬编码深色值：
- `text-slate-300`（第260行 CampDetailPanel 课程大纲）
- `bg-[rgba(255,255,255,0.08)]`（六维测评进度条背景）
- 路径 Block 内的 `text-slate-300` 与浅色背景对比度不足

**建议：** 统一 `text-inherit` + `bg-inherit`，由父级控制颜色主题。

### 4.3 学习进度条在浅色模式下的可见性

**问题：** `bg-white/20` 进度条背景在白色卡片上几乎不可见。

**建议：** 浅色模式下进度条背景改为 `bg-slate-200`。

### 4.4 导师卡片的认证标识

**问题：** 认证讲师有绿色对勾 `@e38`，但未认证讲师（如 BUDDY）也显示类似的在线dot，容易混淆。

**建议：** 统一认证体系：认证 = 金色徽章，未认证 = 灰色虚线边框。

### 4.5 分类 Tab 选中态

**问题：** 当前选中 tab（`bg-slate-900 text-slate-900`）在浅色模式下文字颜色不对——选中项文字应该高亮，不是变黑。

**建议：** 选中态改为 `bg-emerald-500 text-white` 或 `bg-slate-900 text-white`（深色背景高亮）。

## 五、现有 PRD 补充建议（针对 M1）

### 5.1 US 补充：章节测试

**US-EDU-001: 章节学习与测试**
作为学习者，我希望在学完每章后做几道练习题来巩固知识，这样我能确发现自己有没有真正掌握。

Acceptance Criteria：
- [ ] 每章末尾有3-5道练习题（单选/多选/判断）
- [ ] 提交后立即显示得分和正确答案
- [ ] 完成本章测试后才能解锁下一章
- [ ] 测试成绩计入课程整体进度

### 5.2 US 补充：结业考试

**US-EDU-002: 结业考试**
作为完成课程的用户，我希望参加结业考试来验证我的学习成果，这样我能获得正式的课程认证。

Acceptance Criteria：
- [ ] 课程全部章节完成后解锁结业考试入口
- [ ] 考试有时间限制（课程决定：30min/60min/无限制）
- [ ] 提交后显示总分、排名百分比、错题解析
- [ ] 通过考试（≥60分）获得课程电子证书

### 5.3 US 补充：作业提交

**US-EDU-003: 实战作业提交**
作为进阶课程学员，我希望提交实战作业并获得反馈，这样我能将知识转化为实际技能。

Acceptance Criteria：
- [ ] 作业区支持文本输入和文件上传
- [ ] 提交后显示"待批改"状态
- [ ] 导师批改后显示评语和分数（AI批改占位）
- [ ] 优秀作业可被设为公开示例

## 六、技术债务

| 问题 | 影响 | 建议修复方式 |
|------|------|------------|
| `DetailPanel` 对所有 item type 用同一个 component | 路径、共学营、课程结构不同，强行复用会导致显示混乱 | 分离为独立 panel |
| `selectedItem` 类型为 `Record<string, unknown>` | 丢失 TypeScript 类型安全 | 定义 discriminated union type |
| 搭子聊天是 mock 数据 | 无法真实聊天 | 预留 WebSocket 接入点 |
| 无路由系统 | 所有"详情"都是面板覆盖，无法 deep link | 引入 React Router 或 state 路由 |
