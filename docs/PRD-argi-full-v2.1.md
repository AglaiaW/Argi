## 一、愿景与战略定位

### 1.1 核心愿景
> **"让 AI 创作成为可共享、可积累、可复用的社区资产"**

**工具-社区飞轮**的三个咬合点（v2.1重点设计）：
1. **工具→创作** — 每个工具使用后，自动出现"分享到社区"轻量提示
2. **创作→社区** — 作品一键进入社区，降低发布门槛至1秒
3. **社区→激励** — 创作者首个互动（48小时内）系统自动触发

### 1.2 战略定位
- **目标用户：** 有 AI 创作需求的中小商家、内容创作者、个人用户
- **核心差异：** 工具与社区深度融合，非工具货架式陈列
- **商业模式：** 免费工具引流 → 社区内容沉淀 → 企业API/私有化变现

## 二、冷启动策略（★ v2.1 重点补充）

### 2.1 冷启动三阶段

```
Phase 0（上线前，Pre-Launch）：
  - 邀请100名种子创作者（定向邀请，非公开招募）
  - 每人预先填充10个模板/角色（总计1000个内容资产）
  - 种子用户获得"创始成员"标识+6个月免费Pro

Phase 1（0-30天，早期）：
  - 定向邀请扩展至500用户
  - 每日内容产出目标：30个新作品
  - 种子用户互动率达到70%后，再开放公开注册

Phase 2（30-90天，增长）：
  - 公开注册开放
  - 内容密度达到"每10分钟有新内容"后，启动推荐算法
```

### 2.2 种子内容来源
- 内部团队生成（30%）：确保初始内容质量标杆
- KOL合作（40%）：邀请各领域创作者贡献内容，换取曝光位
- UGC引导（30%）：通过激励引导真实用户贡献

### 2.3 新创作者激活目标
> **注册→首次创作 < 3分钟**

设计机制：
- 首次登录直接进入"快速创作"引导流（3步完成首次创作）
- 首次创作完成后，系统自动 bot 点赞+评论（48小时内，让用户感知"被看见"）
- 首次发布后72小时内，获得"新发布"专区曝光保护（20-50次曝光）

### 3.1 用户角色定义

| 游客 | 浏览但未注册 | 40% |

| 付费用户 | 30天内产生付费行为 | 5% |

### 3.2 用户注册流程

```
手机号/邮箱注册
    ↓
验证码认证
    ↓
选择兴趣标签（多选：电商/教育/直播/品牌等）
    ↓

    ↓
```

```
访问（100人）
  ↓ 工具吸引（30%）
工具用户（30人）
  ↓ 创作完成率（33%）

  ↓ 发布转化（30%）
社区发布（3人）
  ↓ 48h互动率（50%）
活跃参与者（1.5人）
```

**v2.1改进：** 每步流失率目标降低，核心通过"首次互动bot机制"保证留存。

## 六、法律合规与版权（★ v2.1 重点补充）

### 6.1 内容版权协议

**用户创作内容归属：**
- 用户保有创作内容的版权
- 用户发布时授予 Argi 非独占、可转授权的展示权
- Remix 内容必须保留原作链接，否则视为侵权

**Remix 规则：**
- Remix 前必须获得原作授权（或原作设为"可Remix"）
- Remix 作品必须显示原作来源（技术实现：创作元数据存储 `originalId`）
- Remix 收益分配：原作10%，平台10%，Remixer80%
- **违规处理：** 举报→3工作日内下架→累犯封号

### 6.2 平台合规义务

- **生成式AI合规：** 依据《生成式人工智能服务管理暂行办法》，所有AI生成内容需有"AI生成"标识
- **内容审核：** 所有用户生成内容须经AI预审（文字→关键词过滤，图片/视频→AI鉴黄/鉴暴）后才能发布
- **数据安全：** 用户个人信息存储符合《个人信息保护法》要求

### 7.1 C端单位经济

| 指标 | Phase 2假设 | Phase 3目标 |

**结论：** B端是主要利润来源，C端是流量池和品牌建设。

```
→ "发布你的Remix版本"引导（v2.1新增） →
→ 填写角色描述 → 设定价格 →
→ 发布到角色市场 → 获得安装量/评价
```
