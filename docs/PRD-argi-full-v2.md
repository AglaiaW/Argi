## 一、愿景与战略定位

### 1.1 愿景
> **"让 AI 创作成为可共享、可积累、可复用的社区资产"**

Argi 不只是"工具集合"，而是**创作-社区飞轮**：
- 工具降低创作门槛 → 作品驱动社区参与 → 社区产出模板/工作流 → 进一步降低门槛
- 这与 SeaArt.AI 的核心理念完全一致：工具即社区，社区即工具

### 1.2 战略定位

| 维度 | SeaArt.AI | Argi v1 | Argi v2.0 |
|------|-----------|---------|-----------|
| 核心价值 | 创作+社区飞轮 | AI工具展示 | **创作-社区飞轮** |
| 用户角色 | 创作者+消费者合一 | 内容消费者 | **创作者+贡献者+消费者** |
| 发现机制 | 社区自组织（点赞/二创） | 分类浏览 | **社交发现+模板推荐** |
| 商业模式 | 社区免费+企业付费 | 待定 | **免费社区+企业API/私有化** |
| 角色系统 | AI角色市场 | 无 | **Agent角色市场** |

## 二、核心产品原则

### 2.1 SeaArt 6 大产品原则（Argi 需对齐）

1. **工具即入口，社区即出口** — 用户因工具来，因社区留
2. **创作即社交** — 每个创作行为都应能触发社区互动
3. **模板即货币** — 创作者通过分享模板获得认可和流量
4. **角色即资产** — AI角色是可积累、可交易、可复用的数字资产
5. **二创即致敬** — "Remix"文化让创作可迭代，而非孤立存在
6. **发现即惊喜** — 无算法推送，靠社区自组织产生意外发现

### 2.2 Argi 社区-工具飞轮模型

```
用户进入
  ↓
┌─────────────────────────────────────┐
│           工具层（Tool Layer）       │
│  M1技能教育│M2 Agent市场│           │
│  M3创作中心│M4超级社区│M5硬件生态   │
└─────────────────────────────────────┘
  ↓ 使用工具创作 ↓ 产出作品
┌─────────────────────────────────────┐
│          社区层（Community Layer）   │
│  作品展示│模板市场│角色市场│讨论区   │
└─────────────────────────────────────┘
  ↓ 模板/角色被复用 ↓ 贡献者获得认可
┌─────────────────────────────────────┐
│          激励层（Incentive Layer）   │
│  创作者等级│打赏│流量扶持│API配额    │
└─────────────────────────────────────┘
  ↓ 更多优质内容 ↓ 更多用户
  ↓ (飞轮闭合)
```

## 三、模块重构设计（基于 SeaArt 原则）

### 3.1 M1 技能教育 → 「创作学院」

**SeaArt 启示：** 教程不是静态页面，是可交互的"创作任务"

| 功能 | v1 现状 | v2.0 设计 |
|------|---------|-----------|
| 课程展示 | 卡片列表 | **任务制** — 每个课程 = 可完成的创作任务 |
| 学习路径 | 文字描述 | **可视化路径图** — 节点=技能，边=递进关系 |
| 课程详情 | 静态描述 | **实战演练** — 边学边做，作品直接进入社区 |
| 效果评估 | 假数据 | **真实AI评测** — 提交作品，AI评分+社区评分 |
| 讨论区 | 空壳 | **学员问答+导师点评** — 活的学习社区 |
| 证书/成就 | 无 | **链上成就徽章** — 可分享到社交媒体 |

**新功能：**
- `CourseTemplate` — 每门课结束后自动生成"学习模板"，可分享到社区
- `LearningPathway` — 可视化技能树，节点可点击预览，完学后变亮
- `AIReviewer` — 提交作业 → AI自动评分+改进建议

### 3.2 M2 Agent 市场 → 「角色工坊」

**SeaArt 启示：** AI角色不是功能，是可拥有、可交易、可二创的数字资产

| 功能 | v1 现状 | v2.0 设计 |
|------|---------|-----------|
| Agent列表 | 硬编码数据 | **动态市场** — 支持筛选/排序/搜索 |
| Agent详情 | 空壳面板 | **完整Agent页** — 能力展示+试用+二创 |
| 数字人 | 仅展示 | **数字人DIY** — 可定制性格/外观/声音 |
| 购买流程 | alert空函数 | **真实购买流** — 积分/订阅制 |
| 试用功能 | 空函数 | **限次试用** — 3次免费试用，促转化 |
| 算力套餐 | 仅展示 | **算力商城** — 按量付费+套餐订阅 |
| 案例展示 | 硬编码 | **真实案例库** — 行业+场景+效果数据 |

**新功能：**
- `AgentCard` 新增：`installCount`、`remixCount`、`rating`
- `AgentDetailPage` — 完整Agent主页，含角色故事、能力展示、用户评价、相关模板
- `RemixAgent` — 克隆他人Agent，修改后发布为自己的版本（致敬原作）
- `AgentShowcase` — 精选Agent推荐，编辑pick

### 3.3 M3 创作中心 → 「创作者工作台」

**SeaArt 启示：** 创作工具和社区完全融合，创作产出自动进入社区

| 功能 | v1 现状 | v2.0 设计 |
|------|---------|-----------|
| 创作入口 | 仅图文 | **多模态** — 图文/视频/角色/声音 |
| 草稿管理 | 列表 | **版本管理** — 每次生成=一个版本，可对比 |
| 一键发布 | alert | **发布到社区** — 作品直接进入发现页 |
| 平台分发 | 空壳 | **多平台同步** — 一次创作，自动适配多平台 |
| 价值包 | 展示 | **模板市场** — 我的模板可被他人购买/复用 |
| 排期工具 | 静态 | **智能排期** — AI推荐最佳发布时间 |
| 数据分析 | 假数据 | **真实数据** — 曝光/点击/转化真实追踪 |

**新功能：**
- `CreationFlow` — 创作→预览→调整→发布的完整流程
- `TemplateMarket` — 模板市场，我的模板被购买获得积分
- `MultiPlatformSync` — 抖音/小红书/公众号等多平台一键发布
- `CreatorAnalytics` — 创作者数据中心，真实数据驱动创作优化

### 3.4 M4 超级社区 → 「灵感广场」

**SeaArt 启示：** 社区是发现引擎，不是讨论板

| 功能 | v1 现状 | v2.0 设计 |
|------|---------|-----------|
| 帖子列表 | 硬编码 | **真实社区内容** — 真实用户/创作/讨论 |
| 知识库 | 仅展示 | **精选知识** — 官方+优质UGC，标签分类 |
| 活动广场 | 假数据 | **真实活动** — 线上/线下活动，报名管理 |
| 人才市场 | 展示 | **供需市场** — 需求方发需求，服务方接单 |
| 发现机制 | 无 | **Trending+Following+Recommended** |
| 互动功能 | 空壳 | **点赞/收藏/评论/Remix/分享** |

**新功能：**
- `TrendingFeed` — 热门创作，按热度/最新排序
- `CreatorProfile` — 创作者主页，含作品集/粉丝/模板
- `RemixChain` — 记录每个二创的原作关系，形成创作链
- `EventLive` — 直播活动，支持实时互动

### 3.5 M5 硬件生态 → 「算力商店」

**SeaArt 启示：** 硬件不是商品页，是"算力即服务"的入口

| 功能 | v1 现状 | v2.0 设计 |
|------|---------|-----------|
| 硬件列表 | 展示 | **算力套餐** — 按需购买，弹性计费 |
| 适配场景 | 文字 | **智能推荐** — 输入用途，AI推荐最优硬件 |
| 购买流程 | 空壳 | **完整下单** — 选配置→看价格→下单 |
| 使用追踪 | 无 | **用量仪表盘** — 真实API调用量/费用追踪 |
| 硬件详情 | 展示 | **算力指南** — 什么场景用多少算力，透明定价 |

**新功能：**
- `ComputeCalculator` — 输入任务类型，估算所需算力和费用
- `UsageDashboard` — 企业用户查看真实用量，支持配额管理
- `HardwareComparison` — 硬件对比表，帮助选型

## 四、通用平台能力

### 4.1 用户系统
- **游客** — 可浏览、可试用Demo，不可发布
- **注册用户** — 可创作、可发布、可购买
- **创作者** — 发布模板/角色，有粉丝，有收益
- **企业用户** — API访问、私有化部署、专属支持

### 4.2 创作资产体系
```
作品（Creation）
  ├── 类型：图文 / 视频 / 角色 / 模板
  ├── 作者：创作者信息
  ├── 可见性：公开 / 私有 / 仅粉丝
  ├── 互动：点赞 / 收藏 / 评论 / Remix
  └── 收益：模板销售 / 打赏

角色（Agent）
  ├── 基础信息：名称/头像/描述
  ├── 能力标签：客服/直播/教育...
  ├── 来源：原创 / Remix
  ├── 授权：免费 / 付费 / 仅粉丝
  └── 安装量 / 评分

模板（Template）
  ├── 关联工具：M1/M2/M3/M4/M5
  ├── 适用场景：电商/教育/直播...
  ├── 定价：免费 / 积分 / 订阅
  └── 使用量 / 好评率
```

### 4.3 积分与激励体系
- **积分（Credits）** — 平台通用货币
- **获取方式：** 创作被购买 / 模板被使用 / 每日活跃 / 拉新奖励
- **消耗方式：** 购买模板 / 购买角色 / 算力充值 / 打赏其他创作者
- **创作者等级：** L1-L5（门槛：作品数+粉丝数+收益额）

## 五、技术与数据架构

### 5.1 数据层
- **用户数据：** Auth0 / 自建用户系统
- **AI能力：** 接入 OpenAI / Claude / 国产模型（Kimi/豆包）
- **存储：** 作品/模板存 OSS，角色配置存 DB
- **搜索：** Algolia / Typesense（全文+向量搜索）

### 5.2 API 设计
```
POST /api/creations        # 创建作品
GET  /api/creations/:id   # 获取作品详情
POST /api/agents           # 创建/Remix Agent
GET  /api/agents/:id       # 获取Agent详情
POST /api/templates        # 发布模板
GET  /api/templates        # 搜索模板
POST /api/orders           # 下单（模板/角色/算力）
GET  /api/analytics        # 创作者数据分析
```

### 5.3 前端技术栈
- **框架：** Next.js 15 (App Router)
- **UI：** Tailwind CSS + shadcn/ui
- **状态：** Zustand（客户端）+ React Query（服务端）
- **动画：** Framer Motion
- **图表：** Recharts
- **地图/探索：** Mapbox / Leaflet

## 八、设计规范（Design Language）

### 8.1 视觉方向
- **整体风格：** 深色科技感 + 渐变点缀（参考 SeaArt 的深色+霓虹）
- **主色调：** `#0a1628`（深蓝黑背景）、`#14D1A0`（主绿）、`#2B59C3`（蓝色）
- **强调色：** `#FFD23F`（金色，用于热门/推荐标记）、`#FF6B6B`（红色，用于热门标记）
- **字体：** Space Grotesk（标题）+ 等宽字体（数据/标签）
- **圆角：** 大圆角卡片（rounded-2xl），小按钮（rounded-xl）

### 8.2 暗色主题（必须）
- 所有模块背景：`#0a1628` 或 `bg-gradient-to-br from-[#0a1628] to-[#1a2744]`
- 卡片：浅色内容块（bg-slate-100）不可在深色背景直接使用
- 文字：深色背景上用白色/浅灰（text-white、text-slate-300）
- 浅色内容块：需要深色边框（border-[rgba(255,255,255,0.08)]）或使用深色版本

### 8.3 交互原则
- **Hover状态：** 边框变亮（hover:border-[rgba(255,255,255,0.12)]）
- **点击反馈：** active:scale-[0.98]
- **加载状态：** skeleton占位，禁止出现空白内容
- **空状态：** 友好插图+行动按钮
